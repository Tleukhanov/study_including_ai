# AI-2 · тренажёр по темам

Локальный статический сайт: короткая теория, разобранные задачи и квиз с мгновенной проверкой ответов. Без сборки, зависимостей и CDN — обычные HTML, CSS и vanilla JS.

## Запуск

Открыть `index.html` в браузере (`file://` работает) или поднять локальный сервер:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем открыть <http://127.0.0.1:8765/>.

## Структура

```
index.html          точка входа, порядок подключения скриптов
css/styles.css      вёрстка, тёмная/светлая тема, квиз, адаптив
js/data.js          COURSE и массив TOPICS
js/app.js           hash-роутер, рендер, квиз, прогресс, тема
js/topics/*.js      по одному файлу на тему
```

Маршруты: `#/` — главная, `#/topic/<id>` — тема.

## Как добавить тему

1. Создать `js/topics/<id>.js` и добавить объект в `window.TOPICS`:

```js
window.TOPICS = window.TOPICS || [];
window.TOPICS.push({
  id: "example",
  num: "01",
  short: "Короткое имя",
  kicker: "Практика · Раздел",
  title: "Полное название темы",
  summary: "Одно-два предложения.",
  accent: "#22d3ee",
  source: "Источник данных",
  theory: [{ title: "…", html: "<p>…</p>" }],
  tasks: [{
    title: "…",
    question: "<p>Условие</p>",
    hint: "<p>Направление мысли, без готового ответа.</p>",
    answer: "<p>Полное решение</p>"
  }],
  quiz: [{
    q: "Вопрос?",
    options: ["A", "B", "C", "D"],
    correct: 0,
    explain: "Почему ответ верный."
  }]
});
```

2. Подключить файл в `index.html` до `js/app.js`.

Требования к квизу: ровно 4 варианта, `correct` — индекс верного, у каждого вопроса есть `explain`. `app.js` проверяет данные и пишет предупреждения в консоль.

## Подсказки

У каждой задачи есть необязательное поле `hint`. Оно показывается в раскрывающемся блоке «Подсказка» между условием и решением: подсказка задаёт направление (какую формулу взять, с чего начать, какую ошибку проверить), но не выдаёт финальный ответ. Если поля нет, блок просто не рендерится.

## Прогресс и тема

- Прогресс: `localStorage`, ключ `ai2-trainer.v1` (лучший результат по каждой теме).
- Тема оформления: `localStorage`, ключ `ai2-trainer.theme` (`dark` по умолчанию).
- Сброс прогресса — кнопка в сайдбаре.

## Публикация

Сайт готов для GitHub Pages: достаточно положить содержимое папки в репозиторий и включить Pages для ветки. Пути относительные, поэтому подпапка репозитория тоже работает.
